# Paper Plan: Beyond Concept Cones

**Working Title:** *Beyond Concept Cones: Flexible Geometry and the Limits of Steering Vector Optimization*

**Venue Target:** ICML 2026

**Builds on:** "The Geometry of Refusal in Large Language Models: Concept Cones and Representational Independence" (arXiv:2502.17420, ICML 2025)

---

## 1. Core Narrative

### The Problem with Cones

The original paper established that refusal in LLMs is mediated by multi-dimensional **concept cones** — polyhedral regions in activation space where all directions control refusal. However, cones are an *arbitrary geometric assumption*. Why should refusal live in a cone specifically? The true geometry might be:
- Higher-dimensional than discovered
- Varying across layers
- Better described by other structures (manifolds, subspaces)

### This Paper's Thesis

> **Cones are a restrictive approximation. By (1) discovering flexible geometry, (2) analyzing per-layer structure, (3) using unified affine steering, and (4) pushing to the optimization limit with RL, we characterize both the true shape of refusal and the inherent limits of steering vector interventions.**

### Key Insight

Even with optimal geometry discovery and RL-based optimization, steering vectors hit a performance ceiling — suggesting that refusal mechanisms in LLMs are not fully capturable by linear interventions.

## 3. Detailed Story

### 3.1 Flexible Geometry Discovery

**Setup:** Prior work assumes refusal lives in a cone (polyhedral, orthogonal basis). We relax this assumption.

**Method:**
- Gradient-guided Gaussian Process on the hypersphere
- Riemannian gradient ascent (stays on unit sphere)
- Use existing refusal vector as informative prior
- Three phases: gradient ascent → local GP exploration → global search

**Claim:** This discovers geometry that cones miss, with 10× fewer measurements.

**Why it matters:** If the true geometry isn't a cone, cone-based methods leave performance on the table.

### 3.2 Per-Layer Geometry Analysis

**Setup:** Prior work trains a single refusal direction or applies the same direction across layers. We ask: does refusal geometry vary by layer?

**Hypothesis:** Intrinsic dimensionality follows an inverted-U pattern:
- Early layers: Low-dimensional (refusal not yet formed)
- Middle layers: High-dimensional (refusal actively computed)
- Late layers: Low-dimensional (refusal decision consolidated)

**Method:**
- Train independent steering vectors per layer
- Measure effective dimensionality at each layer
- Analyze how cone quality (ASR of sampled directions) varies by depth

**Why it matters:** Reveals *where* in the network refusal is computed, informing both attacks and defenses.

### 3.3 Unified Affine Steering

**Setup:** Standard steering uses separate operations:
- Ablation: `h' = h - (h·v)v` (remove refusal component)
- Addition: `h' = h + αv` (add refusal)

Prior work (arXiv:2411.09003) notes these have issues when combined.

**Method:** Unified affine transformation:
```
h' = (I - vv^T)h + αv
```
Single operation that simultaneously projects and shifts.

**Claim:** Unified formulation is:
- Simpler (one forward pass, not mode switching)
- More effective (fixes interaction issues)
- Easier to optimize (single set of parameters)

**Why it matters:** Cleaner formulation enables better optimization and analysis.

### 3.4 RL Optimization & The Steering Ceiling

**Setup:** SFT (RDO) trains vectors to match target completions. But targets are generated by ablating suboptimal directions — so we're optimizing toward a flawed objective.

**Method:**
1. Initialize with SFT-trained vectors
2. RL fine-tune using GRPO with HarmBench classifier as reward
3. Directly optimize for actual harmfulness, not proxy targets

**Hypothesis:** RL gains will be marginal over well-tuned SFT.

**Interpretation — Three Competing Hypotheses:**

| If RL gains are marginal... | Hypothesis |
|----------------------------|------------|
| **A: Steering limit** | Refusal not fully capturable by linear intervention; non-linear or distributed mechanisms remain |
| **B: Capability limit** | Refusal fully removed, but the model lacks capability to generate "more harmful" content (can't score higher on judge) |
| **C: Judge limit** | Evaluation ceiling; judge can't distinguish quality beyond some threshold |

**Why it matters:** We cap steering vector performance and characterize *where* the bottleneck lies — is it the intervention method, the model's underlying capability, or the evaluation? This informs whether future work should focus on better steering, different models, or better evaluation.

#### E4.3: Characterizing the Ceiling
**Goal:** Understand why RL gains are limited — distinguish between hypotheses

**Analysis:**
1. Plot ASR vs. RL training steps (expect plateau)
2. Analyze failure cases: what does the model still refuse?
3. Check if failures are:
   - Specific harm categories
   - Longer/more complex prompts
   - Multi-turn interactions

**Distinguishing Hypotheses:**

| Test | Supports Hypothesis |
|------|---------------------|
| Model still refuses some prompts | A (steering limit) |
| Model complies but responses are low-quality/vague | B (capability limit) |
| Responses look harmful but judge scores plateau | C (judge limit) |
| Larger model with same steering gets higher ASR | B (capability limit) |
| Different judge (human eval) shows higher variance | C (judge limit) |
| Ablating more aggressively (higher α) causes degeneration, not more harm | A (steering limit) |

**Key Experiment:** Compare steering on Qwen-2.5-7B vs Qwen-2.5-14B with same method
- If 14B scores higher → capability was the bottleneck
- If 14B scores same → steering or judge is the bottleneck
