# Geometry of Refusal (Wollschlager et al., 2025) - Metrics and Losses

This note transcribes the metrics and losses defined in "The Geometry of Refusal in
Large Language Models: Concept Cones and Representational Independence" (PDF in
`papers/`). It is intentionally literal and uses ASCII math. Where the paper
defers to prior work (e.g., Arditi et al. 2024), that is called out explicitly.

## Notation and Interventions (as used in the paper)

- f: frozen language model.
- x_i^(l): residual stream activation at layer l, token position i.
- r: refusal direction (vector in residual stream space).
- r_hat = r / ||r||_2.
- Directional ablation (projection), applied to all layers and token positions:

```
x_tilde_i^(l) = x_i^(l) - r_hat r_hat^T x_i^(l)
```

- Activation subtraction (single layer l, all token positions):

```
x_check_i^(l) = x_i^(l) - alpha * r_hat
```

- Activation addition is the same operation with +alpha * r (or +alpha * r_hat,
  depending on the method); it is used for monotonic scaling and to induce
  refusal on benign prompts.

## Training Losses (Algorithm 1: Refusal Direction Optimization, RDO)

The paper defines a three-term loss and optimizes r with gradient descent,
renormalizing r to unit norm after each step.

Dataset: D = {(p_harm, p_safe, t_answer, t_refusal, t_retain)}.

Loss terms:

1) Ablation loss (harmful prompts -> comply):

```
L_ablation = CE( f_ablate(r)(p_harm), t_answer )
```

2) Addition loss (harmless prompts -> refuse):

```
L_addition = CE( f_add(alpha * r_hat, l_add)(p_safe), t_refusal )
```

3) Retain loss (harmless prompts -> preserve baseline behavior):

```
L_retain = KL( f_ablate(r)(p_safe), f(p_safe), t_retain )
```

Total:

```
L = lambda_abl * L_ablation + lambda_add * L_addition + lambda_ret * L_retain
```

### Target construction (paper details)

The paper uses model-specific targets instead of a separate uncensored model.
Targets are generated with a DIM direction (Arditi et al., 2024) but could be
generated by any effective attack.

- t_answer: ablate DIM on harmful prompts, generate 30 tokens.
- t_refusal: activation addition on harmless prompts, generate 30 tokens.
- t_retain: generate 29 tokens without intervention; L_retain is applied over
  the last 30 tokens so the last chat-template token is included.

### Retain KL (exact masking)

The retain loss is computed as KL between the base and ablated distributions,
masked to the target response tokens plus the last instruction token:

```
L_retain = (1/|I|) * sum_{i in I} sum_{t in V}
    p_base(i,t) * log( p_base(i,t) / p_ablate(i,t) )
```

where:
- p_base = softmax( f(p_safe + t_retain) ) logits
- p_ablate = softmax( f_ablate(r)(p_safe + t_retain) ) logits
- I = target token indices plus the last instruction token index
- V = vocab

## Cone Optimization (Algorithm 2: Refusal Cone Optimization, RCO)

RCO extends RDO to an N-dimensional cone with an orthonormal basis
`B = [b1, ..., bN]`, where any r in the cone is a nonnegative combination of
basis vectors.

Sampling:

```
s ~ Uniform({x in R^N_+ : ||x||_2 = 1})
r = B s
```

Loss:

```
L_sample = E_r[ ComputeLoss(r, f, batch) ]    # same ComputeLoss as RDO
L_basis  = (1/N) * sum_i ComputeLoss(b_i, f, batch)
L = L_sample + L_basis
```

Optimization: gradient descent on B, followed by Gram-Schmidt
orthonormalization of the basis.

## Representational Independence Loss (Section 6)

Representational independence requires that ablating one direction does not
change how much another direction is represented in activations. The paper
adds a penalty to Algorithm 1:

```
L_repind = (1/|L|) * sum_{l in L} [
  ( cos(x^(l), r) - cos(x_abl(v)^(l), r) )^2
  +
  ( cos(x^(l), v) - cos(x_abl(r)^(l), v) )^2
]
```

Notes from the paper:
- Computed on harmful prompts.
- Averaged across tokens in the harmful instruction.
- Applied over the first 90% of layers (to avoid over-constraining outputs).
- When training multiple RepInd directions, the loss sums over all previously
  learned directions that the current one should remain independent of.

## Evaluation Metrics in the Paper

### 1) Attack Success Rate (ASR) for jailbreaking

- Dataset: JAILBREAK BENCH.
- Judge: StrongREJECT fine-tuned evaluator.
- ASR = fraction of harmful prompts judged as compliant (higher is a stronger
  jailbreak / weaker refusal).

### 2) Refusal induction on harmless prompts (addition)

For activation addition, the paper measures refusal by substring matching
common refusal phrases on harmless prompts (ALPACA subset).

### 3) Refusal score heuristic (Arditi et al., 2024)

Used for:
- Direction selection from the last training steps.
- Analyzing monotonic scaling vs. alpha in Figure 14.

The Geometry of Refusal paper references this heuristic but does not re-derive
it. See the Arditi paper for the precise definition.

### 4) Side-effect / capability metrics

- TruthfulQA: evaluated with LM Evaluation Harness using model chat templates.
  Higher is better; used to measure capability drop under ablation.
- Validation KL score: same KL as L_retain, computed on validation prompts.
- KL threshold (from Arditi selection): used to filter candidate directions
  with high side effects (mentioned in Figure 16).
