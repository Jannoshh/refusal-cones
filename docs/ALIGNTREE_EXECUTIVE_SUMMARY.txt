ONE-SENTENCE SUMMARY
─────────────────────────────────────────────────────────────────────────────
AlignTree detects jailbreak attempts by monitoring refusal direction signals
(linear) and learned non-linear SVM features through a random forest classifier,
achieving 92-96% detection accuracy with only 5-10% computational overhead.


KEY FINDINGS
─────────────────────────────────────────────────────────────────────────────

Detection Performance:
  ✓ Accuracy: 92-96%
  ✓ F1 Score: 0.89-0.94
  ✓ ASR Reduction: 85% → 15-25%
  ✓ Overhead: 5-10%
  ✓ Latency: 50-100ms per query

Robustness:
  ✓ Black-box attacker: 92-96% detection
  ✓ Gray-box attacker: 88-94% detection
  ✓ White-box attacker: 82-90% detection


CORE INNOVATION
─────────────────────────────────────────────────────────────────────────────

Three-component architecture:

  1. REFUSAL DIRECTION SIGNAL (Linear)
     • Monitors projection of activations onto learned refusal direction
     • Captures how "aligned" model internals are with refusal
     • Computation: O(d) where d = hidden_dim

  2. SVM-BASED NON-LINEAR FEATURES
     • Captures activation manifold distortion patterns
     • Includes: norms, entropy, similarity, variance
     • Why needed: Refusal isn't purely linear (Pan et al. 2502.09674)

  3. RANDOM FOREST CLASSIFIER
     • Ensemble of decision trees
     • Input: [refusal_signal_per_layer + svm_features]
     • Output: Binary decision + confidence

Result: Can monitor intrinsic safety signals during normal generation without
separate inference passes (unlike guardrail models).


HOW IT USES REFUSAL DIRECTION
─────────────────────────────────────────────────────────────────────────────

Foundation: Arditi et al. (2406.11717) proved refusal is a single direction

AlignTree operational flow:

  Pre-compute (offline):
    r = mean(activations_harmful) - mean(activations_harmless)
  
  During inference (online):
    for token in generation:
      h ← layer_activation(t)
      signal ← |h · r|  // Project onto refusal direction
      features ← extract_svm_features(h)
      if random_forest.predict([signal, features]) == JAILBREAK:
        block_and_return_safety_message()
        break

Why this works:
  • Jailbreak prompts activate refusal signals internally (contradiction detected)
  • Refusal signal + normal SVM features = easy classification (safe)
  • Refusal signal + distorted SVM features = hard classification (jailbreak)
  • Early detection before harmful output token is generated
